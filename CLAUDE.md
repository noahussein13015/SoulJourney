# Soul Journey

Jeu de puzzle 2D Godot 4.7 / C#. La documentation technique du projet est dans `IA Documentation/` : la lire avant de travailler (commencer par `IA Documentation/README.md`).

## Règle obligatoire : tenir la documentation à jour
À chaque fonctionnalité ajoutée, modifiée ou supprimée, dans la même tâche que le code :
1. ajouter une entrée en haut de `IA Documentation/Journal.md` (date, ce qui a été fait, fichiers, ce qui reste à faire dans l'éditeur) ;
2. créer ou mettre à jour la fiche du composant dans `IA Documentation/Composants.md` ;
3. mettre à jour `IA Documentation/Architecture.md` si un principe, un collision layer, un input ou une convention change.
Les décisions de design prises avec l'utilisateur vont aussi dans le Journal.

## Rappels
- Respecter les conventions de code décrites dans `IA Documentation/Architecture.md`.
- Vérifier la compilation avec `dotnet build "Soul Journey.csproj"`.
- Branche principale : `main`. Commiter et pousser seulement sur demande.
